# Future ideas

Not planned or built. These are options for later, roughly in the order they would make sense.

1. **Real branding.** Replace the draft logo, colours and tagline. Add photos of the cinema and its screenings, and an `og:image` so links look good when shared.
2. **Contact email.** Create `info@cinematakis.gr` in the papaki panel, then show it on the contact pages. Check papaki's instructions for the correct SPF record (see [`dns-and-domain.md`](dns-and-domain.md)).
3. **Social links.** Facebook or Instagram links in the footer, which suit pop-up events.
4. **Easy editing for non-technical people.** A CMS such as Decap CMS, which edits the same `events.json` through a web form. It needs a login setup, so check security carefully first.
5. **Static site generator.** Move to a tool such as Astro if the site grows to many pages, so the menu and footer are written once.
6. **Ticketing or registration.** If entry stops being free, link to an external ticketing service rather than building one.
7. **Newsletter or event reminders.** Use an external service, and handle consent and privacy (GDPR) properly.
8. **Calendar export.** Let visitors add a screening to their calendar.
9. **Contact form.** Needs a third-party service. Think about spam and privacy first.
